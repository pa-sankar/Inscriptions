Cross-corpus search across SII / ARE / EpCa / TaKa / EpTe.
Sanjay-only. The public site has one corpus live (SII) today, so a cross-corpus tool has nothing to offer a public reader yet — this page is not linked from the public site and stays Sanjay-only until ARE and/or another corpus actually launches there too. Union schema/filter design: see PENDING.md's "Advanced Search / Web platform" section. Not every field is filterable yet — Kind, Language, Script, State, and Dynasty/King aren't offered as filters in this first version (documented gaps: ARE's own Type was never computed, State isn't wired for EpCa/TaKa, Kind means a genuinely different thing per corpus, SII's own Language column is always empty). Click a row for every field (Location, Dynasty, King, Date, Type, and any corpus-specific field) — the results table itself only shows what's needed to identify and skim a row, keeping room for Remarks.
Roman numeral or plain number for SII/EpCa/TaKa/EpTe; a year or year-range for ARE. Blank = every volume.
Embedded: "mahavra" matches "samahavraja" too. Partial: matches "mahavratin" but not "samahavraja". Full: exact word only. Always case-insensitive and diacritic-folded; also matches a record's own unique ID.
