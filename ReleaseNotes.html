Release Notes

2026-09-28

Finding and narrowing records

  • Filters now support multiple selections at once, with an Include/Exclude toggle — pick several volumes, states, or languages together, or exclude a few instead of listing everything else you want.
  • Filters narrow each other as you go. Pick a volume and every other filter's own list shrinks to only the values that actually occur among that volume's records — no more picking a state that turns out to have zero matches for what you already selected. A short note above the filters explains this, and what Reset does.
  • A "Blank / not available" option now appears in any filter where some records genuinely have nothing recorded for that field — select it to find exactly those records.
  • A plain-language summary of your active filters now shows just below the filter row (e.g. "Volume = II · State ≠ Tamil Nadu"), since the filter buttons alone don't say which values are selected.
  • The category filter (where available) now narrows and updates its own counts the same way every other filter does.

Reading the table

  • Click anywhere on a row to open a popup with every field for that record, clearly labeled ("Unique ID:", "Language:", "Dynasty:", ...) — including fields the table itself doesn't show by default. A field with nothing recorded shows "Not available" rather than being left out, so you can tell "checked, nothing there" from "not shown." Remarks gets the most room in the popup, since it's usually what you're most interested in.
  • Only a curated set of columns is shown by default, with the Remarks column given at least half the table's width — any column you filter on is shown automatically. Sl.No now shows right next to the ID by default too, since a volume + serial number is usually enough to pinpoint one specific record.
  • The ID column now shows a compact icon instead of the full record ID — hover it (or tap, on a phone) to see the full ID, or click to copy it. Copy-to-clipboard works exactly as before.
  • Alternating row shading and visible column borders make it easier to read across a row without losing your place.
  • Row height now follows the actual content of each row, instead of every row being padded to a uniform height regardless of how much text it actually has.
  • The "Kind" column shows a short label (e.g. "Stone", "Copper") with the full description available on hover.
  • Page headers were trimmed to the essentials — the sources link and the color legend (explaining what the different text colors/styles mean) are still there, just without a long list of every volume number.

Fixed

  • The "View page" button (for records with a scanned page image available) had stopped appearing for some records — fixed.
  • A number of records in South Indian Inscriptions Vol. I were missing their description and find-spot entirely, even though the information was present in the original scan — fixed for the affected records.
  • A handful of records had been mis-tagged as hero-stone memorials based on a misread index entry (an old word meaning "hero" used as a royal title, not naming an actual memorial) — corrected.
  • Annual Reports on Epigraphy (ARE) records: a "corrections/addenda" table style used in some years was silently dropping its own content — fixed, recovering the missing details for those records.
  • Remarks for a small number of records that run across a page boundary in the original scan had picked up a stray page heading or page number in the middle of the text — cleaned up across the whole South Indian Inscriptions collection.
